============================================================
                    SRC FOLDER
============================================================

FOLDER:
-------
src/

PURPOSE:
--------
The src folder contains the frontend source code of the
RSET Connect project.

The frontend is responsible for displaying the user interface
and allowing users to interact with the application.

It is developed using:

- React
- TypeScript
- CSS

The frontend communicates with the backend through API
requests. It displays the data received from the backend
and sends user actions back to the backend.

MAIN RESPONSIBILITIES:
----------------------
1. Displaying the application interface.
2. Managing student and admin views.
3. Handling navigation.
4. Managing authentication state.
5. Sending requests to the backend.
6. Displaying data from CSV files through the backend.
7. Accepting user input.
8. Providing reusable components.
9. Applying styles to the application.

STRUCTURE:
----------

src/
|
|-- App.tsx
|-- main.tsx
|-- index.css
|
|-- components/
|   |-- layout/
|       |-- Navbar.tsx
|       |-- Sidebar.tsx
|
|-- context/
|   |-- AuthContext.tsx
|
|-- types/
|   |-- index.ts
|
|-- utils/
|   |-- activityCategories.ts
|   |-- navigation.ts
|
|-- views/
    |
    |-- admin/
    |
    |-- auth/
    |   |-- LoginView.tsx
    |
    |-- student/


FRONTEND WORKING FLOW:
----------------------

User interacts with the website
            |
            v
React Component
            |
            v
API Request
            |
            v
Backend Route
            |
            v
CSV Data
            |
            v

            |
            v

            |
            v
Updated User Interface

1. ROOT FILES OF THE SRC FOLDER
============================================================


------------------------------------------------------------
1.1 App.tsx
------------------------------------------------------------

PURPOSE:
--------
App.tsx is the main React application component.

It controls the overall structure of the frontend and
determines which pages or views should be displayed.

MAIN RESPONSIBILITIES:
----------------------
1. Organizes the main application layout.
2. Displays the appropriate view.
3. Connects authentication with the application.
4. Controls the student and admin sections.
5. Handles the overall application navigation structure.
6. Renders the main components of the project.

IMPORTANT:
----------
App.tsx acts as the central component of the React
application.

It connects the main frontend components and views.

The user may see different screens depending on their role.

For example:

Student:
- Student dashboard.
- Attendance.
- Marks.
- Timetable.
- Results.

Admin:
- Admin dashboard.
- Student management.
- Attendance and marks management.
- Data export.
- Examination management.


------------------------------------------------------------
1.2 main.tsx
------------------------------------------------------------

PURPOSE:
--------
main.tsx is the entry point of the React frontend.

It is responsible for rendering the React application
inside the root HTML element.

MAIN RESPONSIBILITIES:
----------------------
1. Imports React.
2. Imports the App component.
3. Imports the global CSS file.
4. Renders the App component.
5. Connects React to the HTML root element.

WORKING FLOW:
-------------

index.html
    |
    v
main.tsx
    |
    v
App.tsx
    |
    v
Application Interface


IMPORTANT:
----------
main.tsx starts the frontend application.

Without this file, the React components would not be
rendered inside the webpage.

4. CONTEXT FOLDER
============================================================

FOLDER:
-------
src/context/

PURPOSE:
--------
Contains React Context files.

React Context is used to share data between components
without passing the same information manually through
every component.

FILE:
-----
AuthContext.tsx


------------------------------------------------------------
4.1 AuthContext.tsx
------------------------------------------------------------

PURPOSE:
--------
Manages authentication-related information throughout
the frontend application.

MAIN RESPONSIBILITIES:
----------------------
1. Stores information about the current user.
2. Manages login state.
3. Handles logout functionality.
4. Provides user information to components.
5. Helps control access to application views.
6. Connects the frontend with the authentication API.
7. Allows different components to access authentication
   information.

WHY CONTEXT IS USED:
--------------------
Several components may need information about the
currently logged-in user.

For example:

- Navbar may display the user's name.
- Sidebar may display role-based navigation.
- Dashboard may need the user's ID.
- Student pages may need the current student's details.

Instead of passing user information manually through
many components, AuthContext makes it available to
the components that need it.

AUTHENTICATION FLOW:
--------------------

LoginView.tsx
      |
      v
AuthContext.tsx
      |
      v
Backend auth.ts
      |
      v
students.csv
      |
      v
Authentication Response
      |
      v
User information is stored
      |
      v
Application views are displayed

============================================================

The src folder is responsible for the complete frontend
interface of RSET Connect.

The components display the appropriate views.
The views send requests to the backend.
The backend processes the requests and accesses CSV files.
The response is sent back to the frontend.
The frontend displays the updated information.
